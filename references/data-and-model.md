# 자료와 모델

## 포함한 자료

기존 웹서비스 계산에 사용되는 학과·과목별 집계 통계와 공개 학교 교육과정 스냅숏을 코드 형태로 포함한다. 개인별 학생 명단, 학번·연락처, 원본 엑셀, 업무메일, 저장된 계획·예측 기록, 배포 인증정보는 포함하지 않는다.

- `lib/registration-data.ts`: 2024~2026년 학년·학수구분별 집계.
- `lib/course-observation-data.ts`: 7개 학과의 과거 과목별 수강실적 집계.
- `lib/university-foundation-data.ts`: 전 학과 통계 보고서의 과목·소속·학년별 집계.
- `lib/course-catalog-data.ts`: 공개 학사서비스에서 조회한 교육과정 스냅숏.

통계의 적용 시점과 연결 조건은 계산 코드가 관리한다. 목표 연도·이후 실적은 예측에서 제외한다. 공개 교육과정 조회는 학교 공개 화면의 조회 경로를 사용하며 학교 시스템 변경이나 네트워크 제한이 있으면 실패할 수 있다. 실패 시 원문/계획 파일을 확인하고 자료를 추측하지 않는다.

## 모델

현재 수학적 산출 버전은 `curriculum-v9-curriculum-compatible-history-2026-10-29`이다. 원본 웹 소스의 기준 커밋은 `source-info.json`에 기록한다. 필수 수용 하한, 선택 학점 경쟁, 자기 학년 이수 가정, 연도·학기 필터와 교육과정 호환 조건을 사용한다.

## 검증 결과의 의미

공과대학 7개 학과의 2026학년도 과목·학기별 217건을 회고 비교했다. 권장정원 대 실제 수강인원의 과목별 오차율 중앙값 23.40%, 산술평균 35.90%, 25% 이내 115건(53.0%)이다. 217건에는 실제 수강인원 0명 과목이 없다. 단순 합산 인원 차이의 비율이나 수강인원 가중 오차율과 혼동하지 않는다.

일부 자료는 개발 중 이미 확인했으므로 독립적인 미래 예측 검증이 아니다. 65개 전공 표기의 통계가 있다는 사실과 그 전체에 동일한 정확도가 검증됐다는 주장은 다르다. 실제 수강인원은 개설·정원 제약을 받은 결과여서 미충족 잠재수요 전체를 직접 측정하지 못한다.

## 소프트웨어와 통계의 구분

코드 라이선스는 통계 원본·학교 명칭·제3자 자료에 대한 권리까지 부여하지 않는다. 공개용 집계에서 개인을 식별하거나 사용자 입력 자료를 재배포하지 않는다. 다른 기관에 적용할 경우 그 기관의 기준과 사용 가능한 자료로 검토한다.
