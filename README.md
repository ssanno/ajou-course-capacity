# 수강정원 플래너 · AI 실행 도구

교육과정·학년별 인원·개설계획을 연결해 과목별 예상 수강인원과 기본 확보 권장정원을 산출합니다. AI는 자료 정리와 설명을 담당하고, 숫자는 이 저장소의 공통 계산 프로그램으로 산출합니다.

- 바로 이용하는 웹서비스: https://ajou-course-capacity.ajou-univ-in-5516.chatgpt.site/
- 이 저장소: 같은 계산 엔진을 사용하는 웹 소스와 명령줄 실행 도구, AI용 `SKILL.md`.
- 현재 모델: `curriculum-v9-curriculum-compatible-history-2026-10-29`.
- 학교 계정 로그인이나 OpenAI·Claude API 키 없이 계산할 수 있습니다. 사용하는 AI 서비스의 이용 조건은 별도입니다.

## 자신의 AI에서 사용하기

파일 처리와 명령 실행이 가능한 AI 환경에서 이 저장소를 열고 다음과 같이 요청하세요.

> 이 저장소의 README.md와 SKILL.md를 읽고, 내 수강정원 산출 작업에 필요한 설치 항목과 변경 파일을 먼저 설명해줘. 계산은 기존 프로그램을 실행하고, 부족한 입력은 질문해줘.

프로젝트 작업 지침은 `AGENTS.md`에 있습니다. 일반 채팅창에 주소만 붙여넣는 것으로 프로그램이 설치되지는 않습니다. 기존 개인 스킬이나 AI 설정을 자동으로 덮어쓰지 않습니다.

## 시작하기

Node.js 22.13.0 이상과 npm이 필요합니다. 설치 명령은 현재 저장소에 `node_modules`와 잠금 파일을 만들며 첫 계산 시 `.capacity-runtime`에 실행 캐시를 만듭니다. 자동 실행용 `postinstall`은 없습니다.

```bash
npm ci --ignore-scripts
npm run forecast -- --input examples/example-plan.json --output results/example
```

출력 파일:

- `prediction.json`: 입력값·모델 버전·과목별 결과가 고정된 예측 기록
- `capacity.csv`: 엑셀에서 열 수 있는 과목·분반별 결과

예제는 사용법 확인을 위한 가상 과목이며 실제 예측 정확도를 입증하는 데이터가 아닙니다.

## 실제 자료 입력하기

현재 웹서비스의 **불러오기 → 현재 계획 파일 저장**으로 내려받은 계획 JSON을 그대로 사용할 수 있습니다. 다운로드한 파일을 `inputs/plan.json`에 두고 실행하세요.

```bash
npm run capacity -- validate --input inputs/plan.json
npm run forecast -- --input inputs/plan.json --output results/my-plan
```

엑셀·PDF만 있는 경우 AI가 표를 확인해 `references/input-format.md`에 맞는 JSON으로 정리하도록 요청하세요. 이 CLI가 임의 형식의 엑셀·PDF를 자동 해석한다고 가정하지 마세요. 웹 화면에서는 기존 엑셀 개설계획 업로드 기능을 사용할 수 있습니다.

필수 입력은 적용 교육과정, 학년별 인원, 대상 학년도·학기, 개설 과목과 분반 수입니다. 알 수 없는 학년별 인원은 0으로 바꾸지 말고 확인해야 합니다. 사용자가 허용한 경우에만 대략적인 인원을 사용하고 결과에 그 사실을 설명하세요.

## 내 PC에서 웹 화면 실행하기

```bash
npm run dev
```

터미널에 표시된 로컬 주소로 접속합니다. 운영용 빌드는 `npm run build`, 실행은 `npm start`입니다. 공개 학교 교육과정 조회를 제외한 계획·예측 기록은 브라우저에 저장됩니다. 브라우저 데이터를 삭제하면 저장 내용도 삭제되므로 중요한 계획은 파일로 보관하세요.

이 배포본은 일반 Next.js 프로젝트입니다. 기존 운영 사이트의 배포 ID, 인증정보, 원격 저장 DB, 원본 첨부파일과 업무메일은 포함하지 않습니다. 두 저장 API는 외부 조회·쓰기를 허용하지 않습니다.

## 계산 원칙과 범위

- 전공필수·기초 과목의 이수 대상 수용 하한을 고려합니다.
- 선택과목은 해당 학과·학년·학기의 과거 학점·수강 비율과 공통 규칙으로 배분합니다.
- 학생은 권장이수순서에 따라 자기 학년 과목을 수강한다고 가정합니다.
- 권장 학기 밖 개설처럼 자동 추정이 불가능한 경우 `확인 필요`로 표시하며 0명으로 단정하지 않습니다.
- 목표 연도와 그 이후의 수강 실적은 예측 근거에서 제외합니다.
- 교원·강의실·인기 편중·개별 사정은 담당자가 별도로 조정합니다.

웹서비스와 동일한 입력·통계·모델 버전을 사용하면 같은 권장정원과 분반별 배분이 나옵니다. 다른 학교에 그대로 적용하기보다는 교육과정, 학점 상한과 통계 기준을 그 학교에 맞게 확인해야 합니다.

## 검증 현황

공과대학 7개 학과의 2026학년도 과목·학기별 217건에 대한 과거 자료 비교 결과입니다.

| 지표 | 값 |
| --- | ---: |
| 서비스 권장정원과 실제 수강인원 간 과목별 오차율의 중앙값 | 23.40% |
| 같은 과목별 오차율의 산술평균 | 35.90% |
| 오차율 25% 이내 | 115/217건 (53.0%) |

과목별 오차율 = `abs(권장정원 - 실제 수강인원) / 실제 수강인원 * 100`. 이는 개발 과정에서 확인한 과거 자료의 비교이며 미래 성능 보장이나 전 학과 독립 검증 결과가 아닙니다. 평균 오차율 25% 목표는 아직 달성하지 못했습니다.

```bash
npm test
npm run check
npm run build
```

배포 패키지의 계산·입력 검증 테스트는 가상 자료를 사용합니다. 내부 검증에 사용한 원본 파일이나 개별 계획은 배포하지 않습니다.
